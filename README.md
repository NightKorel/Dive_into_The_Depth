# 潛淵 · 淵2（Dive into the Depth）

**戰鬥磚塊制新版**。內部代號「淵2」（舊版 `Deep_in_The_Dark` ＝「淵1」）。

純前端遊戲（HTML + CSS + 原生 JavaScript），無框架、無建置流程。
直接用瀏覽器打開 `index.html` 就能玩；改完重新整理即可。

## 現況
戰鬥系統第一版可玩原型，實裝 `設計文件/戰鬥磚塊制_設計.md` §13：
- 池子 12（場上 4 角色 × 每人 3 磚）、每回合補手牌到 8、出招帶容量 15（限數字總和）。
- 基礎傷害（1/5）＋順子加成（基數 3×(長度−1)）＋對子換爆擊（每對 +15%、爆擊 ×2）。
- 回合條件卡（潛淵波動）10 張、開局四人（主角/K/V/L）各自技能、全隊共用血條、一隻會反擊的淵蟲。
- 一鍵順子／一鍵對子。

## 檔案
- `index.html`／`style.css`／`js/game.js` — 遊戲本體。
- `設計文件/` — 設計文件、藍圖、劇情/角色設定（從淵1搬來）。
- `CLAUDE.md` — 給接手 AI 的工作規則（先讀）。
- `更新日誌.txt`／`納可要求清單.txt` — 進度與待辦。

詳見 `設計文件/檔案地圖.md`。
