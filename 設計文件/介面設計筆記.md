# 介面設計筆記 —— 怎麼讓 UI 有質感（可量化的規則）

> 納可 2026-08-16 要 Claude 上網查「讓介面有質感」的具體技法（配色/影子/間距/圓角…）。
> 這份是查來整理的「可直接照做」的規則，之後做淵2 的 UI 都能照這查。來源見文末。
> 一句話總結：**質感 = 克制 + 一致 + 層次**，而且這三樣都有數字可以量化，不是靠感覺。

---

## 一、配色

### 60-30-10 比例（最實用的配色公式）
- **60% 主色**：最大面積。暗色 UI＝一個深中性底（深藍灰/深黑）。
- **30% 次色**：撐起結構的「傢俱色」——面板、卡片、次要文字。跟主色有區別但不搶。
- **10% 強調色**：最亮、最飽和、最跳，**只給最重要的行動**（主按鈕、焦點）。這 10% 是畫面的「生命」。
- 淵2 對應：60% 深藍灰底、30% 面板/文字、**10% 只留給「出擊」紅**。強調色越省越有力。

### 暗色 UI 的鐵則
- **不要用過飽和的顏色**（深底上鮮豔色會刺眼、顯廉價）。用降飽和的色＝Nord 就是這個思路。
- **用同一個色的深淺（tint/shade）造層次，比一堆不同色相更耐看**。研究：一堆「純色、同亮度」的顏色＝又吵又無聊。層次來自明暗，不是來自多色相。
- **限制色數**：一個中性底 ＋ 1~2 個強調色。別五顏六色。

## 二、影子（陰影）

### 分層陰影（professional 的關鍵差別）
- **不要一條濃黑影**。疊 **3~5 條「越遠越大越淡」的影子**＝模擬真實光的散射，柔和自然，單一條影子做不出來。
- 做法：最貼元件的一層＝小 offset、小 blur、較實（定義「接觸邊」）；每往外一層＝offset 和 blur 加大、opacity 減小。
- 顏色用**半透明黑 `rgba(0,0,0,.12~.3)`**，不要純黑 `#000`。
- CSS 範例（浮起的卡片）：
  ```css
  box-shadow:
    0 1px 2px rgba(0,0,0,.20),
    0 2px 4px rgba(0,0,0,.16),
    0 4px 8px rgba(0,0,0,.12),
    0 8px 16px rgba(0,0,0,.08);
  ```

### Material 的「高度分級」概念
- 把陰影分成固定幾級（像 1/2/4/8/16 級），每級一組固定影子＝一致的「離頁面多高」感。
- **越重要/越上層的東西＝影子越大**（浮得越高）。彈窗 > 卡片 > 背景。這本身就是一種層次語言。

## 三、間距

### 8pt 網格（一致感的來源）
- **所有可量的值都用 8 的倍數**：padding、margin、gap、圖示大小、按鈕高度、甚至圓角。
- 常用階：**4 / 8 / 12 / 16 / 24 / 32 / 48**（小元件可用 4 的變體做微調）。
- 好處：所有東西自動對齊、自動一致，不會出現 7px、13px 這種「差一點點就是不對勁」。
- **別出現隨機數字**。定一組間距值，只用那幾個。

### 留白 = 高級感（反直覺但很關鍵）
- **敢留空的設計看起來更貴**。研究說留白能讓「感知價值」差很多；理想上留白佔版面 40~60%。
- **別把每個像素塞滿**。「一個區塊只做一件事、周圍留夠空」比「塞好塞滿」高級。
- 一致的間距節奏 > 塞滿資訊。

---

## 四、圓角（方 vs 圓 vs 角度）

### 圓角要成「系統」
- 用**一組固定圓角值**（例 4 / 8 / 12 / 16 / 24），語意命名（S/M/L）。**別出現隨機的 7px、13px**。
- **嵌套圓角公式（很重要、常被做錯）**：**內圓角 = 外圓角 − padding**。
  - 例：外卡圓角 16、padding 8 → 裡面的元件圓角就用 8。這樣嵌套的角才「同心、順」，不會外圓內方看起來歪掉。

### 方 / 圓 / 銳角＝風格選擇（沒有對錯，一致最重要）
- **大圓角**＝親和、柔和、現代、可愛（手遊、社群 App）。
- **小圓角（2~6px）**＝俐落、精緻、克制（多數精品/工具型 App）。
- **直角/銳角**＝嚴肅、銳利、正式、有力量感。
- **切角/多邊形（clip-path 斜切）**＝科技感、稜角、賽博/軍事風。
- 淵2 是**深淵/黑暗奇幻**：適合「**小圓角或帶一點銳利**」＝比大圓角更有肅殺、沉重感；重點是**全畫面用同一種角**，別這裡大圓那裡直角。

## 五、通用「高級感」原則（貫串以上）

1. **克制**：最貴的設計＝最多留白、最少字體、**一個強視覺當主角**。別什麼都想強調（都強調＝都不強調）。
2. **一致性**：同一套圓角、間距、陰影、色票語言，貫穿整個介面。
3. **層次**：畫面要有明確的「先看哪、再看哪」（一個主 CTA、一個焦點）。靠大小/粗細/對比/留白拉開。
4. **字體層次**：字級與粗細拉開差距（標題大而粗、內文中、標籤小而淡），但**別用超過 2~3 種字體**。

---

## 六、套進淵2 的可行清單（之後可照做，待納可決定要不要）
- **間距全部對到 8pt**：把現在零散的 6/10/12px padding、gap 統一成 8 的倍數。
- **圓角定成一組**：現在有 8/10/11/12px 混用 → 收斂成一組（例 6/10/14），並用嵌套公式讓卡中卡的角同心。
- **面板陰影改分層**：現在多是單條陰影 → 換成 3~4 條疊的柔和陰影，浮起感更自然。
- **色彩比例明確化 60-30-10**：Nord 已經降飽和協調，再明確「出擊紅是唯一 10% 強調」。
- **角度風格定調**：確認淵2 要走「小圓角＋一點銳利」還是別的，然後全畫面統一。
