# 檔案地圖 · 淵2

> 每次動工前先看這裡定位程式碼；改到檔案結構／新增功能就更新這份。

## 遊戲本體（根目錄，GitHub Pages 上線的就是這些）
- `index.html` — 版面：敵人區、隊伍血條、波動卡、出招帶、手牌、按鈕、log。
- `style.css` — 樣式（深淵色調、磚塊依號碼上色：1/5紅打人、2紫減益、3綠保命、4藍增益）。
- `js/game.js` — 全部戰鬥邏輯與畫面。分區：
  - `SKILLS`：21 個技能定義（num/dmg/heal/eff）。
  - `HEROES`：開局四人（主角/K/V/L）與其三塊磚（含二選一的預設選擇）。
  - `CARDS`：回合條件卡（潛淵波動）10 張。
  - `score()`：計分（基礎＋順子＋增益＋對子爆擊）。
  - `collectDef()`：敵傷相關效果（減傷/風壓/精準/冰封/威壓/影幕）在敵人回合結算。
  - 回合流程：`startTurn`（補牌+抽卡）→ 排序列 → `attack`（出擊結算）→ `enemyTurn`（敵人反擊）。
  - `render()`：重畫全畫面；`autoStraight`/`autoPair`：一鍵排列（刻意不算最優）。
